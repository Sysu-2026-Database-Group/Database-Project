## 使用约定

1. **正式口径在 `docs/`**：`specs/`、`design/`、`reports/`、`tasks/`；本目录内容与之冲突时，以 `docs/` 为准。
2. 可随仓库交付的截图和摘要存于 `db/results/`，本机原始输出存于 `.runner/`。历史草稿中的 `drafts/assets/` 是当时的本机截图路径。
3. **过期文档及时删**：内容已合并（如 P11 草稿）或重复（带 `(1)` 的副本）不再保留。
