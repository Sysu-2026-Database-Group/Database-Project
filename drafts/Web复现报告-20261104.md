## 五、并发、幂等、过期与异常

| 场景 | 做法 | 结果 |
|---|---|---|
| 自动过期 | 按约束成对前移时间 4 天，等后台任务 | 60 秒内 2 张转"已过期"，已订量 4 → 0，在架不变 |
| 末件并发 | 卖到剩 1 件，两上下文同时确认 | **只成交 1 笔**，库存 1 → 0 |
| 重复提交 | 同一 `quote_token` 连发两次 | 两次 303，**只新增 1 单** |
| 取货 vs 取消 | 凭证页取消 + 取货页确认同时触发 | 只有取消生效：销售 +0、已订 2→0、在架不变 |
| **三方竞争** | 到期前 3 秒，取消 + 取货 + `expiry --once` 同时开火 | 取消先获锁；过期任务返回 `expired: 0`；取货被拒；账实一致 |
| 参数错误 | 空清单预览 | 400 友好页 + 请求编号 |
| 约束冲突 | 重复 ISBN 建档 | 409，无 `UNIQUE`/表名/SQL 泄漏 |
| 未知路径 | `/no-such-page` | 404 友好页 |
| 连接失败 | 禁用顾客登录并断开其会话 | **503** 友好页；恢复后 200 |
