## 复现

从仓库根目录使用已有 Python 环境执行。完整运行会新建独立的 AuthTests、SaleTests 数据库，SQL 用例由运行器自动执行。AuthTests 的集成用例通过独立数据库用户验证角色，SaleTests 的事务用例使用受限服务连接。

```powershell
.\.venv\Scripts\python.exe -m scripts.project_runner test --config run.example.json --server localhost
```

若已有本次运行器新建、未配置正式员工凭据的 AuthTests 副本，也可重新执行逐项脚本。将示例变量换成本机本轮实际的 AuthTests 库名。

```powershell
sqlcmd -S localhost -E -C -b -f 65001 -i db/tests/week-10-objects.sql -v DatabaseName=实际AuthTests库名
```

逐项脚本使用指定日期和测试角色，正例事务内准备样例并回滚。业务入口负例从无外层事务开始，返回后先记录 `@@TRANCOUNT`、`XACT_STATE()`，确认均为 0 后才比对库存、流水和请求记录。若入口留下事务，判定失败并清理。独立调用内部库存过程时，调用方保留事务，在回滚前检查业务记录。脚本结束时移除临时角色和凭据。

## 本轮修正

空销售区间原来省略了 JSON 的 `records` 字段，现明确返回 `records: []`。销售统计先校验起止日期，再启用查询事务的 `XACT_ABORT`，使空值和反序错误能按原编号返回。原运行库的升级另行执行。
