## 2 经营范围

**卖**

- **图书**（新书）：每一本书以 **ISBN** 区分；
- **文创周边**：文创没有 ISBN，以**内部编码**区分。

**不卖**

- 二手书。

**不做区分**

- 同一商品的**规格变体**（颜色 / 尺寸等）—— 同一个商品的变体**不做成多个商品**。

**货源**

- 向图书批发商、文创供应商采购；
- 同一商品在**不同批次的进价可能不同**。

---

## 3 经营方式

- **渠道**：线下门店零售；线上预订、**到店自提**（无物流配送）。
- **单据**：每次买货、卖货、**预订**都开具单据；**一张单据可以包含多个商品与数量**；**每张单据都有单号**。
  **「开具」= 交给对方一份** —— 卖货与预订的单据会到顾客手里（向供应商买货的那张不进顾客手里）。
  （有哪几种单据、各自挂在哪条业务 → 见 `docs/spec-businesses.md` §1.6；
  单号是干什么用的、退货怎么认单 → 见该文档 **R-22 / R-23**。）

## 4 业务规则

只写「本店有这条规矩」；**数值与算法留到对应业务展开时再定**。

| # | 规矩 |
|---|---|
| 1 | 本店有**会员制度**，会员购买时享有区别于普通顾客的权益 |
| 2 | 会员**不储值** —— 会员身份只是权益凭证，不预存金额 |
| 3 | 商品售价可调整；调价只影响之后的成交 |
| 4 | 库存按**数量**管理：同一个 ISBN 的书 / 同一个内部编码的文创，**仅以数量记录，不追踪到单件** |
| 5 | 线上预订的商品，在**到店自提时才结算** |
| 6 | 架上可能有「**已被订走但还没取走**」的商品，它对其他顾客**不可售** |
| 7 | 新建档的商品**不含售价**，由店长定价；**店长未定价的商品不能卖出** |
| 8 | 入会需**购买会员卡**（收费）；会员卡有**有效期**，到期后不再享有会员权益 |
| 9 | 线上预订的商品有**有效期**；超过有效期未取即失效，被锁的商品重新可售 |

> **规则 8 与规则 2 不矛盾**：买卡费是"买一个会员身份"的一次性支出，**不是预存金额**，所以不算储值。

> **规则 6 与规则 4 不矛盾**：「已被订走」**不落在某一册书上** —— 按"不追踪到单件"的粒度，
> 被订走的是**这个种类的 N 个名额**（即 `docs/spec-businesses.md` 里的「已订量」），
> 所以**不需要知道是哪一册**，规则 4 的"仅以数量记录"仍然成立。
