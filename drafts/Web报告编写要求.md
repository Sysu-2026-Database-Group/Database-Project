**3.8 错误码示例（与 §6.3 对齐）**

| HTTP | 典型业务错误码 | 场景 |
| --- | --- | --- |
| 400 | 参数校验 | 缺失、格式、范围错误 |
| 401 | 认证 | 未登录、会话失效 |
| 403 | `52003` / CSRF | 岗位不足、CSRF 无效 |
| 404 | `52304` 等 | 不存在或无权获知 |
| 409 | `52xxx` / `2601/2627/547` | 业务规则冲突、唯一/外键/CHECK |
| 503 | 连接失败 | 数据库不可用 |
| 500 | 未预期 / 事务失败 | 故障注入、未捕获异常 |
| 405/415 | 协议层 | 方法不允许、媒体类型错误 |

| # | 类别 | 触发方式 | 期望状态 | 错误码 | 可见信息 / 恢复 |

| 1 | 参数/格式/范围 | 页码 0、非数字、超长输入 | 400 | 参数校验 | 字段级提示；不改数据 |

| 3 | 会话失效 | 改岗/停用后旧会话访问 | 401 | 认证 | 要求重新登录 |
| 4 | 岗位不足 | 收银访问店长页 | 403 | `52003` | 统一“无该操作权限” |
| 5 | CSRF 缺失/错误 | 去掉或篡改 token | 403 | CSRF | 操作不生效，可刷新重试 |
| 6 | 不存在/防枚举 | 随机单号、他人单据 | 404 或同形 403 | `52304` 等 | 不泄露记录是否存在 |
| 7 | 业务规则冲突 | 库存不足、超退、状态不允许、资金不足、预览过期 | 409 | `52xxx` | 可重选/重新预览 |
| 8 | 约束冲突 | 重复编码、非法外码、CHECK | 409 | `2601/2627/547` | 不显示约束名与 SQL |
| 9 | 连接失败 | 禁用顾客登录并断会话 | 503 | 连接失败 | 原页重试；恢复后成功 |
| 10 | 事务失败 | 在资金写入点注入故障 | 500 | 未预期/事务 | **无部分写入**；日志有堆栈 |
| 11 | 方法与媒体类型 | 只读路由 POST、错误 Content-Type | 405/415 | 协议层 | 不泄露内部实现 |
| 12 | 幂等重放 | 同键同内容重复提交 | 200/303 | 非错误 | 返回原结果，不新增单据 |

**6.5 异常截图与证据**

- 共 5 张截图：401、403（含 CSRF）、404、409、503；
- 500 不截图，写清“无安全触发手段、不伪造页面”，并以单元测试断言其行为；
- 每张截图写**异常图 5 字段**（见 §三 图证 1），不套用功能图的 7 字段；
- 截图必须能看见**状态提示与请求编号**，不出现内部信息；
- 503 页面需看见“重试”入口；恢复成功用测试记录，不单独截图。

**6.6 数据隔离与可重复**

- 测试只在专用副本运行，不复用演示库；
- 六组连接由配置生成，`skip>0` 视为环境未就绪，**不得记“通过”**；
- 每例结束清理自建单据，样例与指纹恢复；
- 并发用例连续跑 3 次，结果一致才算通过。

**6.7 必须给出的三条断言**

1. **不泄露**：HTML 错误页与 JSON 错误体中均不出现 SQL、表名、约束名、连接串、堆栈；
2. **日志可定位**：同一 `request_id` 能查到动作、岗位、状态、错误码、结果、耗时，且不含口令与完整凭证；
3. **可恢复**：503 恢复后重试成功；409 重新预览后成功；事务失败后数据回到基线。

**6.8 缺陷—修复—复测**

至少 3 条，每条写：现象、发现方式（哪轮/哪个用例）、修复、复测证据。示例候选：索引数量校验、CRLF 审计、删除商品子类残留。

**6.9 未覆盖与 flaky 规则**

- 未覆盖：500 原始输出、另机复现、键盘/打印、并发更高压力；
- flaky：并发用例连续 3 次一致才算通过；**不得用重试掩盖失败**；
- `skip>0` 视为环境未就绪，不记“通过”。
