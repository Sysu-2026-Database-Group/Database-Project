## 一、阻断

### F-01 从零建库必然失败（工具脚本）

**现象**：`setup` 最后一步对象校验失败，报"筛选唯一索引数量不符（7/6）"，此时库已建好、但 `provision` 未执行，配置目录为空，环境不可用。

**证据**：
- `scripts/project_runner.py` 的 `check_objects()` 把数量写死为 6；
- 实际运行库为 7 个，第 7 个 `UX_stock_return_once` 由 `db/return-entry.sql` 引入；
- 失败记录：`.runner/setup-20261104T023331Z8fb351/summary.json`；
- 完整时间线见 `drafts/problem-索引数量校验.md`。

**影响**：任何新机器按 README 从零 `setup` 都会失败；与交接单"新环境可复现"的声明冲突。
