## 二、试画时的画法决策（请 Owner 过目）

1. **子类型**：`goods → book` / `goods → toy` 用**两条空心三角边**（不用一条 ISA 线连两者）——因为两端的 `(0,1)` 与互斥都要表达，分线更清楚；互斥写在线上、约束不画（由 `CK_goods_category` 保证）。
2. **汇总边不画多条同形线**：`C-2`（17 类留痕列）与 `C-8`（`goods` ↔ 三张明细）用**备注框**表达；`C-8` 纯备注、不画代表线（三张明细的 `goods_id` 外码在各自框内文字可见）。
3. **取值来源（C-5）**：两条紫色虚线（`card_type ⇢ sale` 折扣率快照 · `card_type ⇢ fund_flow` 办卡费快照）+ 备注框（升级按两档差价 → `I-20`）。
4. **长途连线走外圈走廊**：`C-5b`（左缘 + 底缘）、`C-14`（右缘 + 底缘）、`C-9`（顶缘）——避免横穿图心。
5. **受控交叉仅 1 处**：`C-18 × C-21`（约 (2190, 405)，90°，位于空白区）——如实记录，未消除（消除代价是再绕一条长途线，得不偿失）。
6. **标签**：29 条连线各一个白底标签，写 `C-x + 两端 (min,max) + 一句话`；位置全部定在空白处。

**形状对比测试结论**（自己导出 PNG 逐一看过）：

| 写法 | 效果 |
|---|---|
| `double=1` | **单细线** ✗ |
| `double=1;strokeWidth=2` ← 原用法 | **单粗线** ✗ ← Owner 看到的就是这个 |
| **`shape=doubleRectangle`** | **真正的两条线** ✓ ← 采用 |
| `shape=doubleRectangle;strokeWidth=2` | 双线且更粗（可选） |
| 嵌套子矩形 | 双线 ✓，但要加子节点、维护麻烦 |

**试过的四种写法**（都做过导出核验）：

| 写法 | 结果 |
|---|---|
