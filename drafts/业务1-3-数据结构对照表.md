# 业务 1-3 数据结构对照表

> **范围**：仅业务 1（商品采购）· 业务 2（商品线下销售）· 业务 3（商品线下取货）
> **依据**：`业务1-3.txt` 顶部「★ 本次敲定（2026-09-15）」块（权威口径以该块为准）
> **粒度**：只写**大类**与**数据语义**，不含 SQL 语法类型；字段名仅为标识符，命名规范未定、可改

---

## 块 0 · 大类字典

| 大类 | 含义 |
|---|---|
| 标识 | 唯一标识一行（单号 / 码） |
| 引用 | 指向另一实体的标识 |
| 编码 | 业务编码（ISBN、内部编码），常被引用 |
| 文本 | 名称、姓名、手机号等 |
| 数量 | 件数 |
| 金额 | 钱（进价 / 售价 / 实收 / 卡费） |
| 时间 | 时刻 / 年份 / 有效期 |
| 布尔 | 是 / 否 |
| 枚举 | 取值有限的固定集合 |
| 行集合 | `[字段, 字段] × N`，即子表（头 + 行） |
| 派生 | 由其他字段算出，不独立存储 |

## 块 1 · 业务动作 ↔ 数据 对照（谁动了谁）

| 业务 | 步骤 | 触碰的实体 | 动作 |
|---|---|---|---|
| 一 | 库管申请 | BuyRequest（写）· GoodsDataset（读） | 建申请单 + 行 |
| 一 | 店长审批 | BuyRequest | 写 is_accepted |
| 一 | 资金计算 | BankAccount | 追加一条「采购付款」变动 |
| 一 | 货物入库 | GoodsDataset | 在库 +N |
| 二 | 顾客选择 | GoodsDataset（读） | 看可售量 / 当前售价 |
| 二 | 收银员结算 | GoodsDataset · BankAccount · 会员接口 | 在库 −N；资金 +实收（销售收款）；积分走接口 |
| 二 | 买会员卡 | BankAccount | 资金 +卡费（会员卡费） |
| 三 | 顾客请求 | 预定系统（查） | 报预定码 + 手机号 |
| 三 | 收银员确认 | 预定系统 | 查状态：已取 / 已过期 / 已取消 → 拒绝 |
| 三 | 收银员结算 | 预定系统 · GoodsDataset · BankAccount | 状态 → 已取；在库 −N、预定 −N；资金 +实收；积分走接口 |

> 「会员接口」= 跨业务调用（细节归业务六），非本表实体。

## 块 2 · 实体字段对照（按实体分组）

### BuyRequest（采购申请）

| 字段 | 大类 | 数据语义 |
|---|---|---|
| 单号 id | 标识 | 采购申请的唯一标识 |
| 供应商 producer | 文本 | 不建实体，需统一写法 |
| 是否通过 is_accepted | 布尔 | 空 = 未审批 |
| 申请时间 apply_time | 时间 | 申请时刻 |
| 行 `[商品, 数量, 价格] × N` | 行集合 | 一张申请单多行；价格为进价 |
| └ 商品 | 引用 | ISBN（Book）或 内部编码（Toy） |
| └ 数量 | 数量 | 申请件数 |
| └ 价格 | 金额 | 进价 |

### BankAccount（资金）

| 字段 | 大类 | 数据语义 |
|---|---|---|
| 总金额 money_count | 金额 | 当前余额 |
| 变动历史 `[金额变动, 原因, 时间, 变动前后金额] × N` | 行集合 | 逐笔留痕 |
| └ 金额变动 | 金额 | 带方向（收 + / 付 −） |
| └ 原因 | 枚举 | 采购付款 / 销售收款 / 会员卡费 |
| └ 时间 | 时间 | 变动时刻 |
| └ 变动前后金额 | 金额 ×2 | 快照，冗余但可校验 |

### GoodsDataset（商品信息数据库）

| 字段 | 大类 | 数据语义 |
|---|---|---|
| 商品 | 引用 | ISBN 或 内部编码（带 Book/Toy 类型标记） |
| 在库数量 | 数量 | = 架上总量，**盘点基准** |
| 预定数量 | 数量 | 已被订走、待自提 |
| 当前售价 | 金额 | 成交计价的依据 |
| （可售量） | 派生 | = 在库 − 预定，**不存列** |

> 注：不做损坏商品相关问题。

### Book（书）

|---|---|---|

| 作者 author | 文本 | —— |

### Toy（文创）

| 字段 | 大类 | 数据语义 |
|---|---|---|
| 名字 name | 文本 | 商品名 |
| 品牌 brand | 文本 | —— |
| 生产日期 produce_time | 时间 | —— |

| （选做）款式 | 文本 | —— |

### 预定系统（业务三最小结构）

| 字段 | 大类 | 数据语义 |
|---|---|---|
| 预定码 lock_id | 标识 | 唯一预定码 |
| 手机号 phone_number | 文本 | 核对身份用 |
| 姓名 member_name | 文本 | 快照 |
| 有效期 lock_ddl | 时间 | 到期即失效 |
| 状态 status | 枚举 | 有效 / 已取 / 已过期 / 已取消 |
| 行 `[商品, 数量] × N` | 行集合 | **不含金额**（预订不冻结价格与积分） |
| └ 商品 | 引用 | ISBN 或 内部编码 |
| └ 数量 | 数量 | 预占件数 |

> **Goods** 是概念、不落实体，= Book + Toy。

## 块 3 · 派生与定式附注

```text
可售量 = 在库 − 预定          （派生，不存列；用于「能不能卖」的校验）

库存定式：
  采购入库  在库 +N
  预  订    预定 +N            （在库不变）
  取  货    在库 −N、预定 −N    （书离店）
  销  售    在库 −N

引用键：ISBN（Book）或 内部编码（Toy），带 Book/Toy 类型标记
资金变动原因：采购付款 / 销售收款 / 会员卡费
```
